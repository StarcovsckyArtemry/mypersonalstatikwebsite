# 🎨 Портфолио графического дизайнера (Артемий Старковский)

Одностраничный сайт-портфолио, созданный для демонстрации работ в сфере графического дизайна. Проект выполнен в виде единого HTML-файла (Single Page Application) и включает в себя современный интерактивный дизайн, плавные анимации и адаптивную верстку.

## ✨ Основные особенности

*   **Современный UI/UX**: Дизайн в стиле минимализма с использованием эффекта «жидкого стекла» (glassmorphism), достигаемого за счет CSS-свойства `backdrop-filter` и SVG-фильтров.
*   **Кастомный курсор**: Уникальный курсор-кольцо, который реагирует на наведение на интерактивные элементы (кнопки, ссылки, карточки портфолио).
*   **Анимации при скролле**: Элементы плавно появляются при прокрутке благодаря `IntersectionObserver`. Также присутствует индикатор прогресса чтения страницы.
*   **Интерактивное портфолио**: 
    *   Фильтрация работ по категориям («Все», «Логотипы», «Баннеры», «Карточки товаров») без перезагрузки страницы.
    *   3D-наклон карточек работ при движении мыши (эффект `perspective`).
*   **Магнитные кнопки**: Кнопки призыва к действию (CTA) слегка смещаются за курсором мыши.
*   **Анимация текста**: В блоке «Обо мне» текст собирается по словам при попадании в область видимости.
*   **Адаптивность**: Сайт корректно отображается на смартфонах, планшетах и десктопах.
*   **Доступность (Accessibility)**: Учтены настройки пользователей с ограниченными возможностями (`prefers-reduced-motion` отключает анимации для тех, кому они мешают).

## 🛠 Технологии

Проект написан на чистом (Vanilla) стеке без использования сторонних фреймворков и библиотек:

*   **HTML5**: Семантическая верстка.
*   **CSS3**: 
    *   CSS-переменные (`:root`) для цветов, шрифтов и анимаций.
    *   Flexbox и CSS Grid для сеток.
    *   Сложные `@keyframes` анимации.
    *   Эффекты размытия и стекла.
*   **JavaScript (ES6+)**:
    *   Управление кастомным курсором.
    *   Логика фильтрации портфолио.
    *   Слушатели событий мыши для 3D-эффектов и «магнитов».
    *   Intersection Observer для анимаций появления.
*   **Шрифты**: Google Fonts (Inter Tight, Instrument Sans, Caveat, Kaushan Script, Nunito).
*   **Графика**: SVG (включая встроенные фильтры) и WebP/PNG (изображения закодированы в Base64 прямо в HTML-файле).

## 🚀 Как запустить

Поскольку весь проект упакован в один файл, для его запуска не требуется установка серверов или сборщиков (Webpack/Vite).

1. Скачайте файл `index.html` (или файл с кодом, который вы прислали).
2. Откройте его в любом современном браузере (Chrome, Firefox, Safari, Edge).

## ⚙️ Как редактировать

Если вы захотите изменить цвета или шрифты, в самом начале CSS-файла (в теге `<style>`) есть блок `:root`. 

```css
:root {
  --ink: #0d0d0c;       /* Основной цвет текста */
  --paper: #efebe2;     /* Цвет фона */
  --acc: #ff4f1f;       /* Акцентный цвет (оранжевый) */
  --acc-2: #f6c343;     /* Дополнительный акцент (желтый) */
}
