# 🤖 Портфолио Python-разработчика и AI-Инженера (Дмитрий)

Одностраничный сайт-портфолио, созданный для демонстрации навыков на стыке веб-разработки, автоматизации и искусственного интеллекта. Проект выполнен в виде единого HTML-файла (Single Page Application) с использованием современного интерактивного дизайна, сложных анимаций и адаптивной верстки.

## ✨ Основные особенности (UI/UX)

*   **Современный дизайн**: Эффект «жидкого стекла» (glassmorphism), достигаемый за счет CSS-свойства `backdrop-filter` и SVG-фильтров.
*   **Кастомный курсор**: Уникальный курсор-кольцо, который реагирует на наведение на интерактивные элементы (кнопки, ссылки, карточки проектов).
*   **Анимации при скролле**: Элементы плавно появляются при прокрутке благодаря `IntersectionObserver`. Присутствует индикатор прогресса чтения страницы.
*   **Интерактивное портфолио**: 
    *   Фильтрация проектов по категориям (например: «Все», «Telegram-боты», «AI-интеграции», «Веб-сайты») без перезагрузки страницы.
    *   3D-наклон карточек проектов при движении мыши.
*   **Магнитные кнопки**: Кнопки призыва к действию (CTA) слегка смещаются за курсором.
*   **Анимация текста**: В блоке «Обо мне» текст собирается по словам при попадании в область видимости.
*   **Адаптивность**: Сайт корректно отображается на смартфонах, планшетах и десктопах.
*   **Доступность**: Учтены настройки пользователей с ограниченными возможностями (`prefers-reduced-motion` отключает анимации для тех, кому они мешают).

## 🛠 Мой технический стек

Проект написан на чистом (Vanilla) стеке, но его содержимое отражает мои профессиональные компетенции:

*   **Backend & AI**: Python, Telegram Bot API, OpenAI API / ChatGPT, написание кастомных промптов.
*   **Frontend**: HTML5, CSS3 (Flexbox, Grid, CSS-переменные, Keyframes), Vanilla JavaScript (ES6+).
*   **Интеграции и автоматизация**: Подключение внешних API, связка ботов с Google Таблицами, CRM-системами и нейросетями.
*   **DevOps (Базовый)**: Деплой проектов, настройка серверов и хостинга для круглосуточной работы ботов (24/7).

## 🚀 Как запустить

Поскольку весь проект упакован в один файл, для его запуска не требуется установка серверов или сборщиков (Webpack/Vite).

1. Скачайте файл `index.html`.
2. Откройте его в любом современном браузере (Chrome, Firefox, Safari, Edge).

## ⚙️ Как адаптировать шаблон под себя

В текущем HTML-коде остались тексты для графического дизайнера. Чтобы превратить его в портфолио разработчика, вам нужно внести следующие изменения:

### 1. Изменить цвета (опционально)
В самом начале CSS-файла (в теге `<style>`) есть блок `:root`. 
```css
:root {
  --ink: #0d0d0c;       /* Основной цвет текста */
  --paper: #efebe2;     /* Цвет фона */
  --acc: #ff4f1f;       /* Акцентный цвет (оранжевый) */
  --acc-2: #f6c343;     /* Дополнительный акцент */
}
